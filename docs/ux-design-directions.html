vllm-calc · UX design directions

Three ways to answer “will it fit?”

Same engine, same tokens (slate + indigo, reserved green / red / amber for status), three layouts for the core loop: adjust an input → see the verdict + VRAM breakdown → fix it → copy the command. Each mock shows the identical scenario: Llama-3.3-70B, AWQ 4-bit, 2× A100 80GB, TP=2.

01

Control Panel

Inputs left, living answer right — the workstation layout. Everything visible at once; nothing hidden behind tabs. Highest information density, best for the expert who tweaks many knobs.
